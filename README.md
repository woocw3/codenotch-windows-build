# Codenotch Windows build

This repository distributes a Windows x64 build of [vinzdg/codenotch](https://github.com/vinzdg/codenotch), version 0.3.0, built from upstream commit [`6c28672c300fadcb7fb59a277ba9d3997d74f1d2`](https://github.com/vinzdg/codenotch/commit/6c28672c300fadcb7fb59a277ba9d3997d74f1d2). The original project is MIT-licensed; see [LICENSE](LICENSE).

**Install:** Download [Codenotch-Windows-v0.3.0-Setup-x64.exe](https://github.com/woocw3/codenotch-windows-build/releases/download/v0.3.0-windows/Codenotch-Windows-v0.3.0-Setup-x64.exe) and double-click it. Follow the installer wizard. It creates a Start Menu shortcut and offers a desktop shortcut.

The [ZIP archive](https://github.com/woocw3/codenotch-windows-build/releases/download/v0.3.0-windows/Codenotch-Windows-v0.3.0-x64.zip) also includes the same Setup executable and portable binaries. For portable use, extract it and run `codenotch.exe`, keeping `codenotch-hook.exe` in the same folder.

Windows may require the Microsoft Edge WebView2 Runtime. Usage data is read from sign-ins on the target PC. Sign in to Codex there, and for Claude Code run `claude auth login --claudeai`. Then restart Codenotch.

This build is unofficial. No credentials, account data, or personal configuration are bundled. The Setup executable is unsigned, so Windows may display a publisher warning.
