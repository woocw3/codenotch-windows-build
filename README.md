# Codenotch Windows build

This repository distributes a Windows x64 build of [vinzdg/codenotch](https://github.com/vinzdg/codenotch), version 0.3.0, built from upstream commit [`6c28672c300fadcb7fb59a277ba9d3997d74f1d2`](https://github.com/vinzdg/codenotch/commit/6c28672c300fadcb7fb59a277ba9d3997d74f1d2). The original project is MIT-licensed; see [LICENSE](LICENSE).

Download **Codenotch-Windows-v0.3.0-x64.zip** from the [Releases page](https://github.com/woocw3/codenotch-windows-build/releases). Extract the ZIP and run `codenotch.exe`. Keep `codenotch-hook.exe` in the same folder. Windows may require the Microsoft Edge WebView2 Runtime.

Usage data is read from sign-ins on the target PC. Sign in to Codex there, and for Claude Code run `claude auth login --claudeai`. Then restart Codenotch.

This build is unofficial. No credentials, account data, or personal configuration are bundled.
